Відповіді на питання:
1. Усі образи, включно з проміжними: docker images -a.
2. Завантажити образ без створення контейнера: docker pull.
3. Розмір і id образу: docker images.
4. Один конкретний образ за репозиторієм і тегом: docker pull репозиторій:тег (наприклад docker pull alpine:3.9).
