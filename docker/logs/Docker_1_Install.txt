Відповіді на питання для закріплення:
1. Версія в офіційному репозиторії Ubuntu може бути не останньою, тому ставлять з репозиторію Docker.
   (У цьому середовищі (WSL, Ubuntu 26.04) пакет docker.io з репозиторію Ubuntu вже свіжий, версія 29.x.)
2. Перший apt update оновлює список пакетів до додавання репозиторію, другий підтягує список пакетів з нового репозиторію.
3. Перевірити встановлення: docker --version, docker run hello-world, systemctl/service docker status.
4. Перевірити джерело пакета: apt-cache policy docker-ce.
